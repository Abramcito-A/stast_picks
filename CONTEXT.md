Documento de Contexto: Parlay Tracker App1. Descripción del ProyectoAplicación dedicada al seguimiento en vivo de parlays (apuestas deportivas múltiples). A diferencia de las casas de apuestas tradicionales, esta app se centra exclusivamente en la experiencia del usuario, mostrando barras de progreso en tiempo real de los picks seleccionados y calculando matemáticamente las probabilidades de éxito restantes.2. Stack TecnológicoBackend: PHP con Laravel.Frontend (Móvil/Web): Vue.js (Options/Composition API).Base de Datos Relacional: MySQL (almacenamiento de usuarios, eventos y tickets).Caché y Colas: Redis (optimización de llamadas a la API deportiva).Tiempo Real: Laravel Reverb (WebSockets nativos para emitir eventos de progreso en vivo).Infraestructura Local: Docker (contenedores para PHP, MySQL y Redis).Despliegue Objetivo: Servidor Linux en la nube (Hetzner).3. Arquitectura de Base de Datos (Core)El sistema depende de 4 entidades principales:users: Propietarios de los parlays.events: Partidos deportivos reales. Se actualizan vía API externa.parlays: Tickets de apuestas agrupadas, vinculados al usuario. Su estado global depende de sus picks.picks: Selecciones individuales. Contienen un target_value (ej. 2.5 goles) y un current_progress (ej. 1 gol actual). Esta tabla gatilla las actualizaciones en la UI.4. Flujo de Datos en Tiempo Real (Data Pipeline)Ingesta: Un cron job / worker de Laravel consulta la API de deportes cada 60 segundos.Procesamiento: El worker actualiza la tabla events.Evaluación: Si el marcador cambia, el sistema busca todos los picks dependientes de ese evento y recalcula su current_progress.Emisión: Si el progreso de un pick cambia, Laravel dispara un evento (PickProgressUpdated) hacia Laravel Reverb.Consumo: La app en Vue.js, escuchando el canal del usuario vía Laravel Echo, recibe el JSON actualizado y llena visualmente la barra de progreso.5.
